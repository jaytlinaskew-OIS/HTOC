ThreatAssessment Scoring — folder map
=====================================
Updated: 2026-08-10

production pipelines (scheduled)
--------------------------------
ThreatAssessScoringV5\         Full 7-day PRISM scorer (task 6:50 AM)
ThreatAssessScoringV5Daily\    First-seen-today scorer (task 7:00 AM)
ThreatScoreIW\                 I&W workbook builder (task 7:15 AM)

Each production folder contains:
  *.ipynb  source notebook
  *.py     hardened scheduled runner
  run_*.bat / run_*_hidden.vbs  Task Scheduler launchers
  logs\    created on first run

prism_score_distribution_report\
